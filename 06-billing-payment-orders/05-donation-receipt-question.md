# Donation receipt / tax documentation requests

## What it is

A donor asking for a receipt or tax documentation for a donation made to WOWSA (a registered nonprofit).

## Where to check

`ewpa/wc-get-order` if the donation was processed as a WooCommerce order. `openwaterswimming.com/docs/` → "Governance & Transparency" category has WOWSA's Nonprofit Status documentation, useful context for tax-related questions.

## How to answer

Confirm the donation amount and date from the order record, and provide it in a format suitable for their records. If they need official tax-deduction documentation beyond a basic receipt, confirm WOWSA's current process for that before promising a specific document.

## Escalate if

They need a formal tax-deductibility letter and you're not sure WOWSA has a standard template/process for issuing one.
