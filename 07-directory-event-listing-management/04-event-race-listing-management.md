# Event/race-specific listing management

## What it is

Organizers managing their event/race listing specifically (distinct from a general coach/organizer profile listing) — this connects to the site's "Certified Events" section (All Certified Events & Race Results, Events/Races, Marathon Associations).

## Where to check

Same Directory add/edit flows as `02-add-new-listing.md`/`03-edit-existing-listing.md`, applied to an event-type listing. If the event has WOWSA-ratified swims associated with it, cross-check **Ratifications Pipeline** (`appgUjmgd0K8WWp31`).

## How to answer

Walk through the same listing docs, being specific that they're managing an event listing (different fields than a person profile: dates, location, race results).

## Escalate if

The event needs to be linked to specific ratified swims/results and that connection isn't visible or editable from the standard listing tools.
