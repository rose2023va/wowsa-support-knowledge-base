# Editing/updating an existing listing

## What it is

Someone who already has a claimed listing wants to update its details (contact info, description, photos, etc).

## Where to check

`openwaterswimming.com/docs/` → "How to Edit Your Listing" article.

## How to answer

Confirm they're logged in and can access their listing's edit view, then point to the docs article for the specific field they're trying to change.

## Escalate if

The edit doesn't save, or changes don't appear live after saving, that's a `10-technical-website-issues/` situation.
