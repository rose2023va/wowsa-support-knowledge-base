# Adding a new listing

## What it is

Someone wants to add themselves, their organization, or an event to WOWSA's Directory for the first time.

## Where to check

`openwaterswimming.com/docs/` → "Add a Listing" category: "How to Add a Listing [First Time Users]" vs "How to Add a Listing or Event [Registered Users]" are different flows depending on whether they already have a WOWSA account, use the right one. "Login and Register" category covers account creation if needed first.

## How to answer

Confirm whether they already have a WOWSA account (check "How to Register"/"How to Login" flow if not), then walk them through the correct add-listing article for their situation.

## Escalate if

They're trying to add something that doesn't fit the standard listing types (coach/organizer/event/association) and you're not sure it's supported.
