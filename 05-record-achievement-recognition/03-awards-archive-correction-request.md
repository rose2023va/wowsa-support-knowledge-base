# Requesting a correction to historical archive data

## What it is

Someone pointing out an error in WOWSA's published Awards history (wrong name, wrong year, wrong category, wrong result) and asking for a correction.

## Where to check

**WOWSA Awards Archive** (`appQIADxmbGpN8PbN`), "Research Issues" table is specifically built to log exactly this kind of thing (fields: Issue, Recommended Action, Priority, Status, Source URL). Check whether it's already logged there before treating it as brand new.

## How to answer

Acknowledge the correction request and confirm you're logging it for review (add a Research Issues record if you have write access and it's not already there, rather than just replying and letting it drop). Don't make the correction yourself in the public-facing Entities/Award Records tables without editorial review, historical accuracy claims need a verifiable source.

## Escalate if

The correction involves a person's identity, achievement legitimacy, or anything reputationally sensitive, always route those to editorial/Rose rather than logging and moving on.
