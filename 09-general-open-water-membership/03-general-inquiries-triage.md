# How to triage an unlabeled/ambiguous General Inquiries thread

## What it is

Not a specific issue type, this file is a triage checklist for when a ticket lands in `SUPPORT/General Inquiries` (or with no label at all) and it's not obvious which of the other 9 categories it belongs to.

## How to triage

1. Check for any Swim ID pattern (`SWIM-####`) anywhere in the thread, if present, it's almost certainly ratification-related (`01-ratification-swim-submission-status/`).
2. Check the sender's domain/signature: news outlet → press (`03-`), business/brand → partnership (`04-`), association name → regional federation (`08-`).
3. Check for course/certification keywords (Safe Coach, Safe Organizer, WOWSA Academy) → `02-course-certification-education/`.
4. Check for payment/order keywords → `06-billing-payment-orders/`.
5. Check for directory/listing keywords → `07-directory-event-listing-management/`.
6. If genuinely none of the above, it's a real general question, handle with `01-general-how-to-questions.md`.
7. If it reads as a complaint, dispute, or safety concern at any point in this process, stop and go straight to `11-next-in-line/complaints-disputes-legal.md` regardless of what category it otherwise resembles.

## Escalate if

After triage, you still can't place it. Flag to Rose, this is exactly the kind of gap that should turn into a new issue file.
