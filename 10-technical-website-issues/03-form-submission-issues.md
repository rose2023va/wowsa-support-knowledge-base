# Jotform/website form not submitting or not received

## What it is

Customer says they submitted a form (ratification, pre-approval, Safer Together interest form, contact form) but got no confirmation, or WOWSA says it never arrived.

## Where to check

Most WOWSA intake forms run through **Jotform**, not a native WordPress form. Search Gmail for the specific form's notification pattern (Jotform sends a notification email to `contact@openwaterswimming.com` on submission, sender `noreply@jotform.com`) using the customer's name/email to see if a submission actually landed. `SUPPORT/Jotform` and `SUPPORT/Forms` labels are the fastest way to see recent form-related threads.

## How to answer

If you find the Jotform notification, confirm receipt with the actual details from it. If you can't find one, ask them to resubmit and confirm the exact form/link they used, some forms have near-duplicate "Clone of..." versions in use (seen with the Safer Together Interest Form), make sure they're using the current one.

## Escalate if

The form itself appears broken (multiple people reporting the same non-submission issue around the same time) rather than an isolated case.
