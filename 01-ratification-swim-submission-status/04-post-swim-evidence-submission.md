# Post-swim evidence/documentation submission

## What it is

A swimmer or team submitting evidence after completing a swim (GPS track, observer log, photos/video, splits) or asking what evidence is still needed to complete their file.

## How to recognize it

"Attached is our GPS track," "what else do you need from us," "sending documentation for [swim]."

## Where to check

- **Ratifications Pipeline** (`appgUjmgd0K8WWp31`), Workflow table: check Notes for what's already on file vs outstanding.
- The rebuild base **WOWSA Ratifications** (`apppdxgNikq9FRbPp`, not yet production) has an "Evidence Completeness" formula and dedicated Evidence table designed for exactly this — not usable for live customer answers yet, but worth knowing it exists for when cutover happens.
- Documentation standards: `openwaterswimming.com/docs/` → "Independent Marathon Swim Ratification."

## How to answer

- Confirm receipt specifically (name what was received), not a generic "thanks, got it."
- If you can tell from Notes what's still outstanding, name it exactly (e.g. "we still need the observer log" rather than "some documents are missing").
- If evidence was sent as an attachment, don't assume it was reviewed just because it arrived, check whether a status update reflects it.

## Escalate if

- Evidence quality/legitimacy is in question (e.g. GPS track looks inconsistent, photo timestamps don't match claimed dates) — this needs a reviewer's judgment call, not a support reply.
